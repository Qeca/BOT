# Агрегатор мероприятий

Telegram-бот команды "Время IceTea" для хакатонного проекта: агрегатор мероприятий, конкурсов и личного кабинета участника. Бот разделяет сценарии студента и администратора, помогает смотреть мероприятия, записываться на них и управлять событиями.

## Возможности

- выбор роли: студент или администратор;
- регистрация и вход по ФИО и группе;
- просмотр ближайших и текущих мероприятий;
- запись участника на мероприятие;
- подтверждение участия через отправку геолокации;
- административное добавление мероприятий и конкурсов;
- рассылка уведомлений участникам.

## Технологии

- Python;
- aiogram 2.x;
- Telegram Bot API;
- FSM-состояния aiogram;
- простая доменная структура `model/` и `repository/`.

## Структура

```text
main.py          # обработчики Telegram-бота и сценарии FSM
keyboards.py     # reply/inline клавиатуры
config.py        # чтение настроек из переменных окружения
model/           # модели Student, Admin и доменные сущности
repository/      # слой хранения и доступа к данным
```

## Запуск

```bash
git clone https://github.com/Qeca/BOT.git
cd BOT
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TOKEN_API="your_telegram_bot_token"
export ADMIN_ID="151023"
python main.py
```

## Безопасность

Токен Telegram-бота должен храниться только в переменной окружения `TOKEN_API`. Не коммитьте реальные токены, `.env` и локальные конфиги в репозиторий.

## Статус проекта

Учебный хакатонный MVP. Код демонстрирует пользовательские сценарии и работу с Telegram FSM, но перед production-использованием нужны полноценное хранилище, валидация данных, тесты и ревизия прав администратора.
